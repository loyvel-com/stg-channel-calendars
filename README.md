# Staging channel calendars

The calendars Airbnb and Booking.com would export for the test places on Loyvel's staging environment. Each place sold
place by place on staging has a calendar feed that points at its file here, and the calendar sync imports the nights as it
imports a real channel's: this repository plays the channels for testing.

Every file holds dates and the channel's own word for a sold night ("Reserved", "CLOSED - Not available"), nothing else:
no guest, no name, no price. The files are generated by `scripts/seed/stg/listings/calendars.mjs` in the backend repository;
do not edit them by hand.
